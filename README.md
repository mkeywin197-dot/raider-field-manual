# Raider Field Manual

An unofficial fan guide for ARC Raiders. It covers guns and their upgrade levels including Amplified V, ARC hit points and weak points, skill builds, maps, benches, the Outpost, quests, items, gear, traders and endgame walkthroughs.

It's a static site: open index.html in a browser, no build step needed.

**Not affiliated with or endorsed by Embark Studios.** ARC Raiders is a trademark of Embark Studios AB.

Data sources: the ARC Raiders Wiki (https://arcraiders.wiki/), official patch notes (https://arcraiders.com/news), RaidTheory/arcraiders-data (MIT), and community guides credited on each page.

Last updated 2026-11-03 for game patch 2.4.0.
